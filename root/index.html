About

Projects

This is my Open GL Theme Park project. It is was developed as a final project for a graphics course. It started with a template containing only the grass, roller coaster, and an odd floating camera system. I updated this world with these features:

  • Trees constructed parametrically
  • A rail for the roller coaster constructed as a sweep object
  • A carousel with hierarchical motion
  • A concession stand with texture mapping
  • An improved navigation system using WASD
  • Toggling to ride the roller coaster

This is a WORDLE style game for guessing birds. It was developed with a function style as a final project for a functional programming course. The game begins with a blurred image of a bird. Players can guess the species of the bird, or have it slightly less blurred. This project also makes use of the OpenCvSharp library to dynamically blur the image depending on the game state. Some future additions to this game might be to load the images from a data base, or apply different filters using OpenCvSharp.

This is a Rust program for simulating a very small subset of old growth forest behaviors. The primary behaviors that are captured in the simulator are mixed age, mixed species, and manual management. This means that trees will multiply, age, and die. There are different trees that multiply and die at different rates. And there are ways for the user to interact by burning sections of the forest.

Another large part of my work at Thermo Fisher was helping design and implement a web application for monitoring, scheduling, and running automated alignments on an electron microscope. I specifically designed pages for viewing the timeline of events on a microscope and the status of samples.
